# Especificações do projeto

O diretório `specs/` é a fonte de referência funcional e arquitetural do Banco Ágil. Estas especificações são independentes de ferramenta, assistente de programação ou IDE.

Qualquer assistente de programação deve consultar as specs antes de alterar comportamentos cobertos por elas. O PDF do desafio permanece a fonte primária dos requisitos.
